# Release checklist

- [ ] Install and commit the dependency lockfile with patched framework versions.
- [ ] `npm run check` passes.
- [ ] Verify core routes, every case-study URL, and the custom 404.
- [ ] Inspect 320/390/768/1024/1440px and 200% zoom.
- [ ] Verify keyboard navigation, clear focus, and skip-to-content.
- [ ] Deny clipboard access and confirm truthful failure feedback.
- [ ] Enable reduced motion and verify optional motion stops.
- [ ] Verify image dimensions/alt text and direct résumé access.
- [ ] Verify current résumé date and outstanding content details.
- [ ] Set the actual production origin and verify canonical/sitemap URLs.
- [ ] Check external project links before making a public launch announcement.
- [ ] Review a Vercel preview, then verify the deployed production version.
